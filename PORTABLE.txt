Music Data Desktop — Windows 11 x64

Запуск: распакуйте архив и дважды нажмите MusicData.exe.
Установка, права администратора и интернет для работы не нужны.
Rust, Cargo, WebView2, Visual C++ Redistributable и внешние кодеки не нужны.
Достаточно одного MusicData.exe. README и SHA256SUMS можно хранить отдельно.

1. Откройте MP3 или перетащите его в окно (до 150 МБ).
2. Измените название, исполнителя, альбом, год, жанр и комментарий.
3. При необходимости выберите обложку JPG/PNG до 3 МБ.
4. Нажмите «Предпросмотр», чтобы проверить теги.
5. Нажмите «Сохранить MP3» и укажите новое имя файла.

Программа не перезаписывает исходный MP3 и существующие файлы.
Аудиоданные не перекодируются. Файлы не передаются по сети.
Комментарий и обложка заменяют все соответствующие ID3-кадры.
«Сбросить изменения» возвращает теги исходного открытого файла.
Другие аудиоформаты пока не поддерживаются.

Архитектура: Windows x64. Это не приложение для Android, iOS, Linux или macOS.
Windows on ARM может запускать x64-программы через встроенную эмуляцию,
но отдельная ARM64-сборка не предоставляется и не тестировалась.

Программа не подписана платным сертификатом издателя. Windows может
показать предупреждение о неизвестном издателе. Подлинность скачанного
файла можно проверить по SHA256SUMS.txt из того же GitHub Release.
